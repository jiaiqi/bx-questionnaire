### 2. 票据

票据解析优先级是（`src/utils/request/env.ts` 的 `resolveTicket`）：

1. **本地存储**（登录/授权链路写入的，小程序端正常走这条）
2. **构建期 `VITE_BX_TICKET`**（仅开发联调用）

小程序端**读不到** H5 那种宿主注入（`window.top.pathConfig` 只存在于 `#ifdef H5` 分支），所以没登录时只能靠 `VITE_BX_TICKET`。开发用票据放在 **gitignored 的 `.env.local`**（不会进产物），需要时再构建。

**票据约 1.5 小时不活动会过期**，表现是 `resultCode=0011` + 「请求服务[xxx]需要登录访问」。

## 三、逐项检查单

### A. 布局（用户明确要求：竖屏 + PC 横屏都要支持）

- [ ] **竖屏**：题目卡片左右留白均匀，选项点击区域够大，底部操作栏不遮挡最后一题
- [ ] **PC 横屏窗口**（开发者工具切横屏或调宽窗口）：内容居中且**不超过 860px**，两侧留白，不拉伸成整屏宽
- [ ] 长题干换行正常，不溢出卡片
- [ ] 分节符（如果有）只显示标题，不显示选项与作答区

### B. 作答与草稿（2026-11-06 起：草稿**只写本机**，作答过程中不再上报后端）

- [ ] 答第 1 题后，界面出现「已保存到本机」，且网络面板里**不应**出现 `srvdaq_activity_result_save` 请求
- [ ] **快速连答多题**（重点）：全程只有 `init_view_select` 类查询，没有任何保存请求
- [ ] 答完最后一题**立刻点提交**：提交请求**不带** `fill_batch_no`（服务端据此新建记录并回传批次号）
- [ ] 退出小程序 → 重新进入同一活动 → 之前的作答应从**本地草稿**回填（同设备、同缓存有效）
- [ ] 换设备 / 清除小程序缓存后再进入：草稿**不会**恢复 —— 这是本次改造的已知取舍（跨设备续答已取消）

## 四、这些「失败」是预期的，不要当成 bug

| 现象 | 原因 |
| --- | --- |
| 结果页答对/答错都是 0、逐题无得分 | **平台侧限制**：`record_reply_merge_select` 未返回 `option_data`/`points`/`result`/`score`，前端无法补偿 |
| 图片上传没有入口 | **平台侧限制**：`file` 应用的写入服务返回「无权限访问」；老工程也没有该功能 |
| 浏览器里结果页显示「未作答」 | 本地跨域拿不到会话 cookie；**小程序与生产同源不受影响** |
| 地址选择提示数据源为空 | 测试环境 `srvconfig_area_adj_select` 可能无数据 |

## 五、真机（非开发者工具）额外注意

开发者工具能连局域网，**真机默认不行**：

- 真机要求 **HTTPS** 且域名在微信后台白名单内；`http://192.168.0.214` 属于 IP + HTTP，真机可能直接拒绝
- 若必须真机联调：在开发者工具里打开「不校验合法域名」后**用工具的真机调试**（不是直接扫码预览），或给测试环境配一个 HTTPS 域名
- 生产环境是 `https://www.gxqcxkj.com/bxapi`，域名与证书正常，真机不受影响

## 七、本清单已核对过的断言

以下断言在提交前逐条对代码核实过，不是凭印象写的：

| 断言 | 代码依据 | 结论 |
| --- | --- | --- |
| 题号不会渲染成「1. 1. 题干」 | `formatQuestionTitle` 用 `/^\d+\s*[.、)）]/` 判断题干是否已带序号，已带则原样返回；答题页与结果页共用同一函数 | 成立 |
| 数字题输入 `0` 不会被当成未作答 | `toArray` 三处都用严格比较（`=== undefined` / `!== ''` / `=== ''`），`mapper` 也用 `String(value) === ''` | 成立 |
| 记录列表失败不显示成「暂无作答记录」 | `RecordList.vue` 中错误态与空态是两个独立分支，错误态带「重新加载」按钮 | 成立 |
| `.env` 不含网关 | `.env` 里只有 `VITE_BX_APP` / `VITE_BX_APP_NO` / `VITE_BX_TIMEOUT` 与两个微信 appid | 成立 |
