设计提案 · 2026-10-22

把纸放到白桌上，让墨蓝只落一次笔

V2 已经把问卷从「一堆盒子」收成「一张纸」。这一步把纸从灰底上搬到白桌上：卡片不再靠底色差浮起， 而靠一圈 1px 的 ring 描边加两层弥散阴影立住；同时把阴影拆成「接触 + 弥散 + 描边」三层合成， 让界面从「干净」走到「有质感」。强调色仍然只有一枚墨蓝，且一屏只出现一次。

一、纸面靠 ring 描边立住

画布回到纯白，卡片用 0 0 0 1px 的阴影描边 —— 不占布局、不掉 1px 边线，移动端也不会出现「双线缝」。

二、阴影是三层合成，不是一团

接触阴影把纸压到桌面，弥散阴影给环境光，ring 描边给边界。三者分开，纸才有厚度而不是发糊。

三、墨蓝一屏只落一次

作答页的墨蓝只给「主按钮」与「当前选中」，进度条改成近墨色 —— 视线自然先落在「下一步该点什么」上。

重构建议

从 V2 到 V3 要动的地方

  • 画布页面底色从灰底改回纯白，卡片靠 ring 描边立住（--bx-bg 退成 --bx-surface）
  • 阴影--bx-elev-1/2/3 换成 Cal 的三层合成公式，接触阴影强度从 0.05 提到 0.28
  • 强调色进度条由墨蓝改近墨色，墨蓝一屏只留主操作与选中态
  • 输入框描边输入框改为 inset 阴影的「井」，聚焦时用主色 ring 代替描边变色
  • 圆角纸面 16、卡片 12、控件 8，统一到一套刻度（此前 6/10/12/16/20 五档）
  • 留白设计器三栏的栏宽 300 / 1fr / 300，属性面板字段间距 16px

为什么值得再动一次

V2 解决的是「整齐」，V3 解决的是「质感」。两者不冲突：结构、令牌名、组件契约都不动，只换画布底色、阴影公式与输入框的两种状态表达 —— 预计改动集中在 tokens.scss 与 6 个组件的 style 块。
