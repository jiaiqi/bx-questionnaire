上一版是「干净但发平」。这一版换掉底色逻辑：画布不再是纯白或灰底， 而是一片缓慢流动的极光；卡片、导航、吸底栏全部换成磨砂玻璃， 背后有光才有质感。内容本身仍然是实底白纸 —— 玻璃负责氛围，纸面负责阅读。

这一版改了什么

  • 材质backdrop blur 22px + 半透明白 + 1px 高光边
  • 底色三团极光缓慢漂移，页面永远有呼吸
  • 图形分数改成环形仪表，维度改成子弹图
  • 反馈按下 scale .97，悬停上浮 2px + 阴影加深

列表是行，设计器是三栏

设计系统

材质、色彩、图形与动效

材质

  • 玻璃backdrop blur 22px + saturate 170%
  • 半透白 62%，强层 84%
  • 边缘1px 白 90% + 顶部高光线
  • 落影0 12px 32px −14px，悬停换 60px 档
  • 实底长表单与表格用纯白纸面，保证可读

色彩

  • 主色天青 → 青绿渐变，只用于主操作与选中
  • 极光靛 30% / 青 26% / 琥珀 22%，大范围低透明度
  • 文字#0B1220 / #475569 / #8A94A6
  • 状态进行中=主色、已结束=中性、未开始=绿

图形与动效

  • 仪表分数用环形仪表，数字与图形并置
  • 子弹图维度条带合格线刻度，不用颜色单独表意
  • 极光26–37s 线性漂移，永不重复的呼吸感
  • 反馈按下 scale .97，悬停上浮 2px + 阴影加深
  • 落笔选项标记 scale 0→1，260ms spring

落到工程里要改什么

  • 画布--bx-bg 换成极光底（页面级伪元素，静态渐变兜底），卡片底改半透明白
  • 降级小程序端不支持 backdrop-filter：改为「不透明浅色卡 + 主色落影」，视觉降级但结构不变
  • 阴影新增 --bx-shadow-brand（主色落影）与 --bx-glass-* 一族
  • 图形结果页分数改 SVG 环形仪表（小程序用 canvas 或 CSS 圆环近似），维度条加刻度
  • 动效极光漂移只在 H5 端开（小程序端动画成本高），其余过渡两端一致
