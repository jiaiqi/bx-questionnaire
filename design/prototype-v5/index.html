一份认真排版的
纸质问卷，搬到屏幕上

不是玻璃拟态，不是灰阶极简。这一版回到产品本身：园区员工填的是一份问卷， 它应该像一份设计精美的纸质问卷 —— 暖白的纸、墨色的字、科技蓝的落笔、 大方的留白。没有多余的装饰，只有排版、字重和呼吸感。

这一版改了什么

  • 底色暖白 #FAF9F6，像打印纸，不刺眼
  • 强调科技蓝 #2563EB，现代、清爽、有分量
  • 质感柔和多层阴影，纸叠在桌上的感觉
  • 排版字重对比拉开层级，留白大方

设计系统

色彩、材质、图形与动效

色彩

  • 底色暖白 #FAF9F6，像打印纸
  • 强调科技蓝 #2563EB，唯一强调色
  • 文字#1C1917 / #57534E / #A8A29E
  • 状态进行中=科技蓝、已结束=中性、未开始=绿

材质与阴影

  • 纸面纯白卡片 + 柔和多层阴影
  • 阴影0 1px 2px + 0 4px 12px，像纸叠在桌上
  • 悬停上浮 1px，阴影加深一档
  • 圆角8 / 12 / 16 / 20，纸面 20、卡片 16、控件 12

动效

  • 时长120 / 180 / 380 / 800ms
  • 落笔选项标记 scale 0→1，240ms spring
  • 进度宽度过渡 380ms
  • 降级prefers-reduced-motion 全部归零

落到工程里要改什么

  • 令牌--bx-bg 改 #FAF9F6，--bx-blue 改 #2563EB，阴影换柔和多层
  • 组件选中态从「浅蓝底 + 蓝描边」改「浅科技蓝底 + 科技蓝描边」
  • 按钮主按钮从墨蓝改科技蓝，hover 加深 + 微浮
  • 排版标题字重 700、字距 -0.02em；正文行高 1.75
